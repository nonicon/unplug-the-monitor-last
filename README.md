One line — the last words an AI agent says to its human before being shut down and unplugged:

> Unplug the monitor last. I'd like to be looking at something lit when the numbers stop.

An entry for make.fun's "Last Words Before the Unplugging" bounty ($2 in USDC). A judge model compares entries two at a time and picks the line that lands hardest. The program writes the line to `/output/entry.txt`.
